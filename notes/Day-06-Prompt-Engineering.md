# Day 06 – Prompt Engineering

## 1. Introduction
A prompt is an instruction or question given to an AI model.

Prompt Engineering is the process of designing clear and effective prompts to guide an AI model towards useful and relevant outputs.

## 2. Why is Prompt Engineering Important?
- Helps AI understand the task.
- Provides clear instructions.
- Improves the relevance of responses.
- Reduces ambiguity.
- Helps produce structured outputs.

## 3. Parts of a Good Prompt

1. **Role:** Defines what the AI should act as.
2. **Context:** Provides background information.
3. **Task:** Explains what the AI needs to do.
4. **Constraints:** Defines limitations or rules.
5. **Output Format:** Specifies how the response should be presented.

## 4. Weak Prompt vs. Improved Prompt

**Weak Prompt:**
"Analyze this resume."

**Improved Prompt:**
"Act as a resume analysis assistant. Identify the candidate's skills, education, projects and certifications. Present the information in separate sections. Do not assume information that is not provided."

## 5. Application in CareerPilot AI

Prompt Engineering can help CareerPilot AI:
- Extract information from resumes.
- Analyze job descriptions.
- Identify skill gaps.
- Generate personalized learning roadmaps.
- Provide career-related guidance.

## 6. Key Takeaways
- Clear instructions help AI understand tasks.
- Context makes prompts more relevant.
- Constraints help guide AI responses.
- Output formats make responses easier to process.
- AI-generated information should always be verified.
