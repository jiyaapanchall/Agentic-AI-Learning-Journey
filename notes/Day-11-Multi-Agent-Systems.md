# Day 11 – Multi-Agent Systems

## 1. Introduction
A Multi-Agent System (MAS) is a system in which multiple AI agents collaborate to achieve a common goal.

Each agent can have a specialized responsibility.

## 2. Single Agent vs. Multi-Agent System

- Single Agent: One agent handles the task.
- Multi-Agent System: Multiple agents collaborate and divide responsibilities.

## 3. Types of Agents in a Multi-Agent Workflow

Examples:
- **Coordinator Agent:** Organizes and coordinates tasks.
- **Resume Agent:** Analyzes resumes.
- **Job Agent:** Analyzes job descriptions.
- **Skill Gap Agent:** Identifies missing skills.
- **Planner Agent:** Generates learning plans.

## 4. Important Concepts

- **Coordination:** Organizing agents' activities.
- **Delegation:** Assigning tasks to agents.
- **Communication:** Sharing information between agents.
- **Collaboration:** Working together towards a common goal.
- **Orchestration:** Managing the overall workflow.

## 5. How Multi-Agent Systems Work

1. A user provides a request.
2. A coordinator identifies the required tasks.
3. Specialized agents perform their assigned tasks.
4. Agents share their results.
5. The workflow combines the results.
6. The final response is provided to the user.

## 6. Advantages
- Divides complex tasks into smaller tasks.
- Allows specialized responsibilities.
- Supports collaboration.
- Can make complex workflows easier to organize.

## 7. Challenges
- Coordination complexity.
- Increased development effort.
- Possible communication errors.
- Higher costs in some implementations.
- More testing and monitoring requirements.

## 8. Application in CareerPilot AI
CareerPilot AI could use specialized agents for:
- Resume analysis.
- Job description analysis.
- Skill gap identification.
- Personalized learning roadmap generation.

A coordinator could manage the workflow and combine the results.

## 9. Key Takeaways
- Multiple AI agents can collaborate towards a common goal.
- Agents can have specialized responsibilities.
- Orchestration coordinates their work.
- Multi-agent systems are useful for complex tasks.
- Not every AI application needs multiple agents.
