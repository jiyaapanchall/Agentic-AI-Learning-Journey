# Day 05 — Context and Memory in AI Agents

## 1. What is Context?

Context is the information available to an AI model that helps it understand the current request or situation.

It may include:
- Previous messages in a conversation.
- User instructions.
- Relevant documents.
- Information related to the current task.

**Example:** If a user previously mentioned learning C++, the AI can use that information when recommending a programming project, provided it is available in the context.

## 2. What is Memory?

Memory allows an AI agent to retain useful information and retrieve it later when needed.

**Example:** A learning assistant remembers a student's completed topics and suggests the next topic in their learning journey.

## 3. Types of Memory

### Short-term Memory

Information retained during the current conversation or task.

Example: Remembering a user's budget while planning a trip.

### Long-term Memory

Information stored for retrieval across future conversations or tasks.

Example: Remembering a student's learning progress for future study sessions.

Note: Actual AI systems can implement memory in different ways.

## 4. Context vs Memory

| Context | Memory |
|---|---|
| Information available now | Information retained for future use |
| Helps understand the current task | Helps recall useful past information |
| Can include recent conversation | Can store information across sessions |

## 5. How Does an AI Agent Use Memory?

A basic memory workflow:

1. Receive information.
2. Identify relevant information.
3. Store useful information when appropriate.
4. Retrieve stored information when needed.
5. Use the retrieved information to generate a relevant response.

## 7. Key Takeaways

- Context helps an AI understand the current situation.
- Memory helps an AI retain and retrieve useful information.
- Short-term memory is generally used within a current interaction or task.
- Long-term memory can persist across future interactions.
- Memory can support personalised AI applications.
