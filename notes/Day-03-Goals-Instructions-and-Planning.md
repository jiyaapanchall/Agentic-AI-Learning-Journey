# Day 03 — Goals, Instructions and Task Planning

## 1. What is a Goal?

A goal is the final result an AI agent is expected to achieve.

**Example:** Help a student prepare for a Python examination.

## 2. What are Instructions?

Instructions guide an AI agent on how it should complete a task.

Examples:
- Use beginner-friendly language.
- Give practical examples.
- Focus on important topics.
- Follow the user's requirements.

**Remember:** A goal explains what needs to be achieved, while instructions explain how to approach it.

## 3. What is Task Planning?

Task planning is the process of deciding which steps are required to achieve a goal and in what order they should be completed.

For example, to prepare a student for a Python examination, an agent might:

1. Identify the exam topics.
2. Understand which topics need more practice.
3. Prioritise the topics.
4. Create a revision timetable.
5. Evaluate progress and update the plan.

## 4. What is Task Decomposition?

Task decomposition means breaking a large task into smaller, manageable tasks.

**Example:**

Main goal: Find three beginner-friendly C++ courses.

Smaller tasks:
- Search for C++ courses.
- Check their difficulty level.
- Compare their content.
- Select suitable courses.
- Present the recommendations.

## 5. Decision-Making in AI Agents

An AI agent may need to choose what to do next based on the user's goal, instructions, available tools and information.

For example, if it cannot find enough suitable courses, it may try a different search or explain the limitation instead of inventing results.

## 6. CareerPilot AI Example

For a student who wants to become ready for a software developer internship:

- Goal: Improve internship readiness.
- Instructions: Consider the student's existing skills and experience.
- Tasks: Analyse the resume, identify skill gaps and suggest learning activities.
- Decisions: Prioritise relevant missing skills.
- Result: Generate a personalised learning roadmap.

## 7. Key Takeaways

- Goals define the result an agent should achieve.
- Instructions guide how the agent should work.
- Task planning organises the steps needed.
- Task decomposition breaks large tasks into smaller ones.
- Agents may need to make decisions when situations change.
