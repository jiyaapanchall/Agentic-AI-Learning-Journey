# Day 10 – Vector Databases and ChromaDB

## 1. Introduction
A vector database stores and searches numerical representations of information called vectors.

It is commonly used in AI applications for semantic search and information retrieval.

## 2. What Are Embeddings?
Embeddings are numerical representations of information such as text or images.

They help AI systems identify similarities in meaning.

## 3. Normal Database vs. Vector Database

- Normal databases commonly search structured records and exact values.
- Vector databases support similarity searches using vector representations.

## 4. Introduction to ChromaDB
ChromaDB is an open-source vector database used in AI applications.

It helps developers:
- Store embeddings.
- Store documents and metadata.
- Perform similarity searches.
- Retrieve relevant information.

## 5. Important Terminology

- **Vector:** A numerical representation of data.
- **Embedding:** A numerical representation of information.
- **Collection:** A group of related records.
- **Metadata:** Additional information associated with stored data.
- **Similarity Search:** Finding information with similar meaning.
- **Query:** A search request.

## 6. How ChromaDB Works

1. Documents are loaded.
2. Documents are divided into chunks.
3. Embeddings are generated.
4. Data is stored in a ChromaDB collection.
5. A user submits a question.
6. Relevant information is retrieved through similarity search.
7. An LLM can use the retrieved information to generate an answer.

## 7. Application in CareerPilot AI

ChromaDB could help CareerPilot AI:
- Store career-related documents.
- Retrieve relevant learning resources.
- Support document-based question answering.
- Provide context for personalized career guidance.

## 8. Key Takeaways
- Vector databases store and search vector representations.
- Embeddings help identify semantic similarity.
- ChromaDB is a vector database for AI applications.
- Metadata provides additional information about stored records.
- Vector databases are useful in RAG systems.
