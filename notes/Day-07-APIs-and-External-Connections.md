# Day 07 – APIs and External Connections

## 1. Introduction
API stands for Application Programming Interface.

An API allows different software applications to communicate and exchange information.

## 2. How APIs Work
1. A user or application sends a request.
2. The API receives the request.
3. The external server processes it.
4. The server sends a response.
5. The application uses the returned information.

## 3. Important API Terms
- **Request:** A message asking for information or an action.
- **Response:** The result returned by the server.
- **Endpoint:** A specific API address.
- **JSON:** A common format for exchanging structured data.
- **API Key:** A credential used to authenticate API access.

## 4. HTTP Methods
- GET – Retrieve information.
- POST – Send or create information.
- PUT – Update existing information.
- DELETE – Delete information.

## 5. APIs and AI Agents
AI agents can use APIs to interact with external applications and services.

Examples:
- Connecting to AI models.
- Retrieving information.
- Saving user data.
- Accessing external tools.
- Automating tasks.

## 6. Practical Learning
A Python application can use the requests library to send HTTP requests and receive JSON responses.

## 7. Application in CareerPilot AI
CareerPilot AI could use APIs to:
- Connect with an AI model.
- Retrieve job-related information.
- Communicate with its backend.
- Save student progress.
- Generate personalized learning plans.

## 8. Key Takeaways
- APIs allow applications to communicate.
- HTTP methods define the type of request.
- JSON is commonly used for exchanging data.
- APIs help AI agents interact with external services.
- API credentials must be protected.
