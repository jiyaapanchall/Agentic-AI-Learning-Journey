# Day 02 — Understanding AI Agents

## 1. What is an AI Agent?

An AI Agent is a system that uses artificial intelligence to work towards a specific goal. It can understand a task, plan steps, use available tools, perform actions and evaluate the result.

Unlike a basic chatbot, an AI agent can work through multiple steps to complete a task.

## 2. Chatbot vs AI Agent

| Chatbot | AI Agent |
|---|---|
| Mainly responds to questions | Works towards a goal |
| Usually conversation-based | Can perform multiple steps |
| Mainly provides information | Can use tools and take actions |
| May not plan tasks | Can plan and evaluate tasks |

Note: Some modern chatbots also have agent-like capabilities.

## 3. Important Terms

### Goal
The final result an AI agent wants to achieve.

Example: Find suitable Python learning resources.

### Task
A smaller activity that helps achieve the goal.

Example: Identify beginner-level Python topics.

### Tool
An external capability that an agent can use.

Examples: Search engines, calculators, APIs and databases.

### Action
An operation performed by the agent using its available capabilities.

Example: Searching for Python tutorials.

## 4. How Does an AI Agent Work?

A basic AI agent follows a cycle:

1. Understand — Understand the user's request.
2. Plan — Decide the steps needed.
3. Act — Use tools and perform actions.
4. Evaluate — Check the result and decide whether more work is needed.

This cycle can repeat until the task is completed or the agent needs help.

## 5. Real-World Example

Suppose a user asks an AI agent to find three beginner-friendly Python courses.

- Goal: Find three suitable courses.
- Task: Search and compare available courses.
- Tool: Search engine.
- Action: Search for courses and collect information.
- Evaluation: Check whether the courses match the user's requirements.

## 6. Key Takeaways

- An AI agent works towards a specific goal.
- Goals can be divided into smaller tasks.
- Agents can use tools to perform actions.
- Agents can evaluate their results.
- Not every chatbot is an AI agent.
