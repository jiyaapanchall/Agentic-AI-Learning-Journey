# Day 09 – Introduction to LangGraph

## 1. Introduction
LangGraph is a framework used to build stateful AI workflows and agents.

It helps developers organize multiple tasks, decisions and interactions into a connected workflow.

## 2. Why LangGraph?
- Supports multi-step AI workflows.
- Helps manage workflow state.
- Supports conditional decisions.
- Allows workflows to use tools.
- Supports human-in-the-loop interactions.

## 3. Important Concepts

### Nodes
Nodes represent individual tasks or steps in a workflow.

Examples: Resume Analysis, Skill Extraction and Job Matching.

### Edges
Edges connect nodes and define the flow between tasks.

### State
State stores information that is shared and updated during workflow execution.

## 4. How a Workflow Works
1. A user provides input.
2. The workflow starts.
3. Nodes perform individual tasks.
4. Edges determine the next step.
5. The workflow may make conditional decisions.
6. The final result is returned.

## 5. Human-in-the-Loop
Human-in-the-loop means involving a human in an AI workflow for review, approval or corrections.

It helps maintain control over important actions.

## 6. LangChain vs. LangGraph
- LangChain provides components and integrations for building LLM applications.
- LangGraph helps organize stateful and multi-step workflows.

They are related technologies and can be used together.

## 7. Application in CareerPilot AI
LangGraph could coordinate the following tasks:
- Resume analysis.
- Skill extraction.
- Job description analysis.
- Skill gap identification.
- Learning roadmap generation.

## 8. Key Takeaways
- LangGraph helps build structured AI workflows.
- Nodes represent tasks.
- Edges connect tasks.
- State carries information through a workflow.
- Conditional paths allow workflows to make decisions.
- Human approval can be included when needed.
